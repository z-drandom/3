## 气体检测合格判据

| 指标 | 合格值 |
| --- | --- |
| 氧含量 O₂ | 19.5 % ~ 21 %（体积分数） |
| 可燃气 | ≤ 10 % LEL |
| 硫化氢 H₂S | ≤ 10 mg/m³ |
| 一氧化碳 CO | ≤ 30 mg/m³ |

检测在作业前 30 min 内完成；作业中断 > 30 min 须重新检测。

通风换气量：**Q = n·V**（换气风量 = 换气次数 × 空间容积），受限空间取 n ≥ 3 次/h。
